## 🎯 Problem Statement

**SIH Problem ID:** SIH26044
**Theme:** Smart Automation
**Category:** Software

The current education system focuses on degrees and marksheets, but **industry needs real skills**. This creates a massive **skill gap** between what students learn and what companies require.

**Edu-Link AI solves this with:**
- Skill-first assessment (not resume-first)
- Explainable AI (not a black box)
- Career Twin (dynamic skill profile)
- Three-sided fit (Student + College + Industry)

---

## ✨ Key Features

### 🎓 For Students
- **Resume Upload + AI Skill Extraction** — NLP-powered automatic skill detection
- **Career Twin** — Dynamic, always-updating skill profile
- **Skill Gap Analysis** — See matched vs missing skills for any target role
- **Explainable Internship Matching** — Every match shows WHY (matched/missing skills)
- **Placement Readiness Score** — Data-driven employability metric
- **One-click Internship Applications**

### 🏛️ For Colleges
- **Student Analytics Dashboard** — Real-time skill insights
- **Top Skills Heatmap** — Branch-wise skill distribution
- **Placement Readiness Tracking**
- **Industry-aligned Curriculum Insights**

### 🏢 For Companies
- **AI-Matched Candidates** — Skill-based ranking (not resume filtering)
- **Explainable Match Scores** — See why a candidate fits
- **Shortlist / Hire Actions** — One-click pipeline management
- **Post Internships** — Simple, skill-focused job posting
